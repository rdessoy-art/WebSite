# Newsletter Popup Implementation Guide

This guide explains how the newsletter popup works and how to add it to additional pages.

## Overview

The newsletter popup appears after 20 seconds, or once the visitor has scrolled about 40% of the page (whichever comes first), on every page and includes:
- A name field for user's name
- An email field for user's email address
- An image of Harrison Dessoy racing (`images/optimised/idm-assen-*.{avif,webp,jpg}` via `<picture>`; original in `images-src/`) displayed on the left
- Mailchimp integration for newsletter signups
- 7-day dismissal period (won't show again for 7 days after closing)

## Files

- `newsletter-popup.css` - Styles for the popup
- `newsletter-popup.js` - JavaScript functionality
- `newsletter-popup.html` - HTML markup (reference only)

## How to Add to a New Page

**As of 2026-07-10 the modal markup is generated by `renderNewsletterPopup()` in `newsletter-popup.js` — never hardcode the `<div id="newsletterPopup">...` block into a page.** That's exactly the copy-paste drift this refactor removed (index.html had its own drifted inline copy of both the CSS and JS before the fix). Add the popup to any page in 2 steps:

### 1. Add CSS Link to `<head>`

```html
<link rel="stylesheet" href="newsletter-popup.css">
```

### 2. Add the script and call the render function before `</body>`

```html
<script src="newsletter-popup.js"></script>
<script>
    renderNewsletterPopup();
</script>
```

`renderNewsletterPopup()` injects the full modal markup (image, form, hidden iframe) via `insertAdjacentHTML` — see the function itself in `newsletter-popup.js` if you need to change the markup; `newsletter-popup.html` is a static reference copy of the same markup for viewing in a browser, not something pages should copy from.

## Configuration

### Timing
The popup appears after **20 seconds** or at **40% scroll depth**, whichever comes first. Both are constants at the top of `newsletter-popup.js`:

```javascript
const NEWSLETTER_DELAY_MS = 20000;      // time-based trigger
const NEWSLETTER_SCROLL_DEPTH = 0.4;    // scroll-based trigger (40% of the page)
```

### Accessibility
The dialog has `role="dialog"` and `aria-modal="true"`. **Esc** closes it, **Tab**/**Shift+Tab** stay inside it, and focus returns to the previously focused element on close.

### Dismissal Period
The popup won't show again for **7 days** after being closed. To change this, edit `newsletter-popup.js`:

```javascript
const NEWSLETTER_DISMISS_DAYS = 7;   // in newsletter-popup.js
```

### Image Path
The image paths are set to `images/optimised/idm-assen-*`. If pages are in subdirectories, you may need to adjust the paths:
- For pages in root: `images/optimised/idm-assen-960.jpg` (etc.)
- For pages in subdirectories: `../images/optimised/...` or adjust as needed

## Features

- **Name Field**: Captures user's name (FNAME field in Mailchimp)
- **Email Field**: Captures user's email (required)
- **Image**: Displays racing image on the left side
- **Responsive**: Stacks vertically on mobile devices
- **Auto-hide**: Automatically hides after successful submission
- **Mailchimp Integration**: Submits to Mailchimp list via iframe
- **LocalStorage**: Remembers dismissal for 7 days

## Testing

To test the popup:
1. Clear localStorage: Open browser console and run `localStorage.removeItem('newsletterPopupDismissed')`
2. Reload the page
3. Wait 20 seconds (or scroll about 40% down the page) for the popup to appear
4. Test the form submission with a valid email

## Troubleshooting

### Popup doesn't appear
- Check browser console for errors
- Verify `newsletter-popup.js` is loading
- Check localStorage: run `localStorage.getItem('newsletterPopupDismissed')` in console
- Clear the dismissal: `localStorage.removeItem('newsletterPopupDismissed')`

### Styles look wrong
- Verify `newsletter-popup.css` is loading
- Check that CSS variables are defined in the page (--primary, --secondary, etc.)

### Form doesn't submit
- Check network tab to see if request is being sent
- Verify the Mailchimp action URL is correct
- Check that the hidden iframe exists
